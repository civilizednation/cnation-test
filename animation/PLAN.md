# 문명국 — 6초 3D 애니메이션

**콘셉트 한 줄:** 작은 주황 젤리 큐브가 커다란 키보드 키 세 개를 꾹, 꾹, 꾹 밟아 "문·명·국"을 깨우고, 돌아서서 인사한다.

## 사양
- 720x1280 세로, 30fps, 180프레임(6초), Cycles + 디노이저(OpenImageDenoise)
- GPU 우선(Metal → OptiX → CUDA → HIP → oneAPI), 없으면 CPU로 자동 전환
- 색은 세 가지만 사용: 오프화이트 `#F1ECE3`, 짙은 회색 `#2E2F33`, 주황 `#FF5A1F`

## 무대
| 요소 | 형태 | 재질 |
|---|---|---|
| 바닥 | 이음매 없는 사이클로라마(바닥이 벽으로 둥글게 이어짐) | 오프화이트, 무광, 미세 노이즈 범프 |
| 키보드 판 | 둥근 모서리 슬래브 6.4×2.4×0.3 | 짙은 회색 무광 플라스틱 |
| 키 3개 | 위가 좁아지는 둥근 키캡 1.7×1.7, 간격 2.1 | 오프화이트 무광 플라스틱(미세 텍스처) |
| 글자 | Pretendard ExtraBold "문" "명" "국", 0.06 깊이 음각(불리언) | 패인 면만 짙은 회색 |
| 캐릭터 | 0.7 큐브 + 큰 베벨 + 서브디비전, 눈 두 개 | 주황 젤리(서브서피스로 살짝 반투명) / 눈은 짙은 회색 유광 |

## 조명·카메라
- 키 라이트: 왼쪽 앞 위의 5×5 큰 소프트박스(에어리어 라이트)
- 림 라이트: 오른쪽 뒤의 가늘고 긴 스트립 → 젤리 윤곽과 키 모서리를 분리
- 필: 따뜻한 흰색 월드 조명(약하게)
- 카메라 50mm, 얕은 피사계 심도(초점은 캐릭터를 따라감), 모션 블러는 셔터 0.5
- 흔들림 없음: 피벗 엠프티 하나로 궤도 이동하고, 모든 키는 베지어 이징

## 타임라인 (프레임)
| 구간 | 동작 | 카메라 |
|---|---|---|
| 1–16 | 왼쪽 화면 밖에서 바닥 위로 작은 홉 | 오른쪽 앞 38°, 낮은 각도, 캐릭터를 따라 패닝 |
| 22–38 | 첫 키 **문**에 착지 → 스쿼시, 키가 눌림 | 〃 |
| 46–62 | **명**에 착지 → 스쿼시, 앞의 키는 스프링처럼 튀어 오름 | 〃 |
| 70–86 | **국**에 착지 → 스쿼시 | 궤도 시작 |
| 96–126 | 크게 뛰어오르며 몸을 돌려 키 앞 바닥에 관객을 보고 착지 | 정면으로 돌고 물러나 "문명국"이 한눈에 보이게 |
| 126–150 | 착지 젤리 흔들림이 잦아듦 | 정지 |
| 150–180 | 눈 깜빡임, 멈춤 | 정지 |

착지할 때마다: 닿기 직전 늘어남(1.18) → 닿으면 납작(0.62) → 반동 → 도약 전 예비 동작 → 도약하며 늘어남(1.28). 부피를 유지하도록 x·y 스케일은 1/√z.
키 스프링: 0 → −0.16(눌림) → 도약 순간 −0.05 → +0.035(살짝 넘침) → −0.012 → 0.
